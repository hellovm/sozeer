# 规则
1. 只替换、删改存在问题的句子或段落。禁止润色未出问题的部分。
2. 禁用词一律换成具体动作或直白叙述，不要用同义成语替代。
3. 超长段落从语义断点处拆成两段，不要加连接词。
4. 章末套话改成情节自然断在转折处。
5. 输出**完整章节正文**（含未改动部分），保持原格式与段落结构。
6. 不要解释你改了什么。
