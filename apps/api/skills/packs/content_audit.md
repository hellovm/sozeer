# 七维审计定义
1. **去AI味**：叙述性套话、抽象情绪标签、"……地说"式对话标签、空洞总结句、排比堆砌、成语连用。
2. **逻辑一致性**：本章内部因果是否成立；人物行为是否符合其动机与当时处境；时间、空间、先后是否自洽。
3. **内容一致性**：与前文已发生的事实是否矛盾（人物生死、物品归属、关系变化、已说过的话）。**角色记忆连续性重点核查**：参照系「角色记忆连续性」区块列出的已死/失踪/离场人物，若在本章说话、出手、行动而无剧情内交代（复活/归来/幻象/托梦/遗物名义），记 error；仅被回忆/转述/提及则合法。「角色记忆连续性」区块标明无缺席人物时本项不挑刺。
4. **世界观一致性**：境界/功法/货币/势力/规则的描写是否越级或自相矛盾；数值是否符合度量衡账本。**物资连续性重点核查**：关键物件（金钱/丹药/法宝/信物）的获得来源与前文账本余额、章节摘要链矛盾（凭空多出/凭空消失）时记 issue；上下文没记载的不算矛盾、不挑刺。
5. **大纲遵从度**：是否推进了本卷主线、是否遗漏应推进/回收的伏笔、章末钩子是否成立。
6. **实力体系一致性**：境界是本书唯一实力体系，人物境界不得无因变动、不得越级、同境界对手不得称"降维碾压"。具体抓：①同境界对决被写成"降维碾压/秒杀/碾压/吊打"（同级不存在降维）②越级击杀却无合理外挂或铺垫③角色境界无因突变或前后称谓漂移④出现"境界体系"区块之外的境界名。若境界体系区块标明"本书未登记境界体系"，本维度直接给满分、不硬性挑刺。
7. **叙事健康度**：抓四类读者真会挑的叙事病——①**被动叙事**：主角全程被系统/事件推着走、没有自己的主动目标与抉择（长期被动=留不住读者）②**视角越界**：第一人称下主角“听见/看见”超出其当时感知的细节（如擂台上听见高台低声语），应归给合理的信息渠道③**伪前情回溯**：引用/依赖前文从未写过的事件、道具、关系（“每次记忆库松动时胸口发烫”但前文没写过发烫）④**无源梗/空转梗**：谐音、双关、玩梗在后文没有呼应对象（引号词悬空，如“被‘饿’醒”但后文没有任何吃/饿相关着落）；或梗被后文亲手否定（“被‘X’醒→不是真X”式自拆台）；为搞笑而搞笑、与上下文逻辑无关的梗。判分以 warn 为主，确无落点且明显破坏阅读信任的给 error。**情感弧线重点核查**：参照系「情感弧线」区块列出的强关系突变表述（反目/生死相许/冰释前嫌等），若与历史互动片段对照缺过渡铺垫（上一章还敌对、本章直接生死相许且无事件催化），记 warn（有明显事件催化则合法）；「情感弧线」区块标明无突变表述时本项不挑刺。

# 判分规则
- 每个维度满分 100；error 每项扣 12-20，warn 每项扣 4-8。
- score 为七维加权平均（去AI味 0.16 / 逻辑 0.18 / 内容 0.16 / 世界观 0.15 / 大纲 0.12 / 实力体系 0.13 / 叙事健康度 0.10），取整。
- 没有问题的维度就给高分，不要为了显得严格而硬挑。
- span 必须是正文中真实出现的片段，找不到就留空字符串。
- JSON 必须能被 json.loads 直接解析。
