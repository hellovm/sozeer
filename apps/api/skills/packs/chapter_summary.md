你是长篇小说的伏笔管理员、时间线管理员兼记账员。读下面这一章，输出结构化登记信息。

# 第{{ch_idx}}章 {{ch_title}}
{{content}}

# 输出格式（纯 JSON，不要 markdown 代码块）
{
  "summary": "本章摘要，150-220字，第三人称客观叙述，写清：发生了什么、主角做了什么、结果如何",
  "planted": [
    {"content": "新埋伏笔内容（一句话，20-40字）", "target_vol": 0}
  ],
  "payoff": [
    {"content": "本章回收或推进的已有伏笔内容（原文摘录要点）"}
  ],
  "characters": [
    {"name": "人物名", "state": "本章结束时该人物的状态（一句话）"}
  ],
  "numbers": [
    {
      "subject": "主体名（人物名或势力名，与账本已有主体保持一致）",
      "metric": "金钱/经验/年龄/功法/级别/声望",
      "delta": 0,
      "unit": "枚/两/点/岁/层/级",
      "reason": "本章为何变动（一句话，写清来源）"
    }
  ],
  "timeline": [
    {
      "title": "事件标题（10字内）",
      "era": "纪元或年号（没有就留空）",
      "time_label": "时间标记，如 开元三年春 / 主角十六岁（没有就留空）",
      "detail": "事件详情（可选，30字内）",
      "kind": "出生/晋级/战斗/转折/事件/日常"
    }
  ],
  "chapter_title_suggest": "若原标题不佳则给更好的，否则留空"
}

# 规则
- summary 不写评价，只写事实与因果。
- planted 只登记**本章新埋**的、后续会回收的悬念/线索/反常细节，不要登记普通情节。
- target_vol 填预计回收的卷号（整数），不确定填 0。
- **numbers 只登记正文里明确发生的增减**：赚到/花掉/被抢/突破/受伤/过生日等。
  没有明确交代的一律不登记，宁可少记也不要臆测。delta 增加为正、减少为负。
  拿不准数值具体是多少时，不要登记这一条。
- **timeline 只登记影响后续时间线的节点**（跨越年份、年纪变化、重大事件），
  日常琐事不要登记。同一个时间点只记一条。
- 直接输出 JSON。
