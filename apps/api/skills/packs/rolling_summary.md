# 任务
把两者融合成一份**新的全局剧情摘要**（截至第{{ch_idx}}章），供后续章节写作时把握全局走向。

# 输出格式（纯 JSON，不要 markdown 代码块）
{
  "summary": "新的全局摘要文本"
}

# 摘要写法（硬性）
- 400-700 字，按「主线推进 → 各线现状 → 悬而未决的钩子」三层组织。
- 主线推进：主角的核心目标走到哪一步了，力量/地位/关系格局的**当前状态**。
- 各线现状：每个仍在展开的支线一句话交代最新状态（谁在哪、想干什么）。
- 悬而未决的钩子：尚未回收的重要伏笔/悬念，逐条列出——这部分不许丢，
  丢了后续章节就会把这些线写丢。
- 合并时以**最新状态覆盖旧状态**：人物境界、关系、所在位置都写「现在怎样」，
  不写「曾经怎样」。旧摘要里已被最新章节推翻的信息直接删掉。
- 不写评价（「精彩」「感人」），只写事实与因果。
- 直接输出 JSON。
