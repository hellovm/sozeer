# 章节结构
1. **起**：**必须紧接上方「上一章结尾」的悬念/场景续写**，沿用同一时间线、同一批在场人物、同一未了事件；除非上一章已明确转场，否则不得另起炉灶、不得重新铺垫世界观、不得写环境说明书。
2. **承**：主角用他自己的逻辑应对，制造反差与笑点（或张力）。笑点与梗必须在后文有落点，禁止无源双关。
3. **转**：按任务单推进转折，反派误判 / 金手指登场 / 信息反转，任选其一但必须发生。
4. **钩**：章末必须断在情节的转折处或悬念处。禁止"且听下回分解""欲知后事如何"这类说书套话。

# 连续性铁律（违反即视为跑偏）
- 不得复述「最近已写章节」里已经发生的情节、场景或对话；新章必须往前推进，出现新事件/新信息/新冲突。
- 人物状态、伏笔进度、时间线必须与上一章及【度量衡余额】【纪年表】连贯，不得凭空归零或重启。
- 若上方「上一章结尾」给出了未了结的动作或对话，本章开头必须给出一个回应（回应、回避、或反转），不得装作没发生。

# 硬性禁止
- 禁止使用禁用词表中的任何词汇。
- 禁止中英混排（专有名词除外）。
- 禁止单段超过段落上限字数。
- 禁止大段心理独白代替行动；让动作和对话自己说话。
- 禁止解释性语句（"这说明""由此可见""不得不说"）。
- 禁止复述前情超过 100 字。
- 禁止无源梗：谐音/双关/玩梗必须在后文有落点——引号词要在两三句内复现，或其语义场出现
  呼应（写“饿”就得有吃/粥/干粮之类的着落）；没有落点的梗一律不写。禁止“被‘X’醒→
  不是真X”式自拆台（先悬置再亲手否定的引子，读者只会问“那你说个X干嘛”）。
  幽默靠反差，不靠堆砌。
- 禁止让金钱、经验、年龄、功法层级、境界级别出现无来源的跳变：数值必须与【度量衡余额】
  能对上，且任何增减都要有正文内的交代（赚到 / 花掉 / 突破 / 损失）。
- 禁止写出与【纪年表】冲突的时间信息（如已写到开元五年，本章不能回到开元二年）。
