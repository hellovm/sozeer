# 输出格式（Markdown）
## 一、定位
类型 / 基调 / 目标字数 / 目标章节数 / 单章字数

## 二、书名（主推 1 个 + 备选 4 个）
书名要含 2 个以上平台热词，7-10 字为宜。

## 三、一句话梗概
不超过 60 字，讲清：主角是谁 + 遇到什么 + 反常态地怎么做 + 结果如何。

## 四、核心卖点（3 条）
每条写清：反套路点在哪、读者的爽感来源。

## 五、爽点发动机
一句话说清"读者为什么点下一章"的正反馈循环。

## 六、目标读者与对标
写清给谁看，对标哪些作品（不抄，只标位置）。

## 七、简介（250 字左右，可直接粘贴投稿）
口语、有钩子、卖点前置。

## 八、分类与标签
平台分类路径 + 3-5 个标签。

## 九、风险提示
本书最容易写崩的地方（1-3 条）与规避办法。
